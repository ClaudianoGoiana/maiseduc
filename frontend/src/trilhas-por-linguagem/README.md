# Trilhas por linguagem

Esta pasta contem uma trilha independente por arquivo JSON. Cada arquivo preserva o formato original da aplicacao:

- `id`
- `name`
- `icon`
- `color`
- `modules[]`
- `modules[].missions[]`

Arquivos disponiveis:

- `c.json`
- `csharp.json`
- `cpp.json`
- `css.json`
- `go.json`
- `html.json`
- `java.json`
- `js.json`
- `kotlin.json`
- `php.json`
- `python.json`
- `sql.json`

Cada trilha possui 12 modulos e 120 missoes. Para usar uma trilha em outro site, carregue o JSON escolhido e use o objeto raiz como a trilha da linguagem.
